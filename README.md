# AlphaSync 直连版

AlphaSync 直连版是一套面向索尼相机的无线传图工具，由相机端和手机端两个应用配合使用，支持浏览相机存储卡、查看照片预览、下载原图，以及自动同步新拍摄的照片。

本项目基于 [BI2QFA/AlphaSync](https://github.com/BI2QFA/AlphaSync) 修改，由 [LuoTianyi007](https://github.com/LuoTianyi007) 维护，属于非官方改进版，不代表原作者的官方发布。

原项目作者：**BI2QFA**。感谢原作者及相关开源项目提供的基础代码。

## 主要功能

### 无线连接与传输

- 在可互通的局域网中发现并连接相机。
- 支持相机连接手机热点或已有 Wi-Fi。
- 优化网络发现、保存地址重试及断线重连。
- 浏览相机 SD 卡中的目录和文件。
- 下载 JPG、ARW 等原始文件，支持断点续传。
- 显示相机到手机的数据接收速度。
- 相机端支持后台运行，方便边拍边传。

“直连版”仍需要相机端运行服务，并建立可互通的网络连接；不代表无需配置 Wi-Fi，也不保证在所有网络环境下都能自动连接。

### 照片浏览与预览

- 支持 JPG、ARW 文件筛选。
- 支持按时间排序，以及不同的列表和网格显示方式。
- 记住上次浏览的目录、文件类型筛选和显示方式。
- 优先处理新拍摄照片的预览任务。
- 支持大图查看、左右翻页、双指缩放、拖动和手动旋转。
- 支持查看照片 EXIF 信息。
- 改善平板、横竖屏切换及全屏预览布局。

### 自动同步

- 提供自动同步总开关。
- JPG 和 RAW 下载开关可分别设置；同时开启时，两种文件均加入下载任务。
- 记住自动同步及文件类型设置。
- 初始化扫描时，将已有照片作为基线，自动同步之后发现并确认的新照片。
- 原图下载与预览任务协调，优先保障照片预览。

自动同步下载的是原始文件，不只是缩略图。同步列表或下载队列中的“已加入”不代表文件已经下载完成，请查看传输状态。

### 照片分析工具

大图查看页面提供：

- **直方图**：支持亮度和 RGB 通道显示。
- **斑马纹**：支持选择亮度阈值，并提供各阈值的参考用途。
- **明暗色块**：支持多种层次数量，便于观察构图和明暗分布。

上述分析基于当前显示的照片或预览图，不是 RAW 传感器数据分析。斑马纹用于标记达到所选亮度阈值的区域，不能单独用于判断 RAW 是否已经过曝。

这些工具只影响 App 内的显示，不修改相机或手机中的原文件。

### 本地相册

- 在 App 内按影集浏览手机或平板上的照片。
- 支持通过文件选择器打开未被系统相册收录的图片。
- 本地照片可使用直方图、斑马纹和明暗色块工具。
- 提高高像素本地照片的显示分辨率，同时控制解码内存占用。

相册显示范围受系统权限和媒体索引影响。若只允许访问部分照片，App 无法显示全部影集；仅存在于云端或其他应用私有空间中的照片，也不一定能直接读取。

## 下载与安装

请从本仓库的 [Releases](https://github.com/LuoTianyi007/AlphaSync-Direct/releases) 页面下载配套的手机端和相机端安装包，并阅读对应版本的发布说明。

### 手机端

手机端修复版使用独立包名，可与原版 AlphaSync 并存。首次使用时，请按 App 提示完成连接配置。

若手机同时连接其他 Wi-Fi 并开启热点，不同设备的网络路由行为可能不同。如发现连接或传输异常，可先关闭其他 Wi-Fi 进行对比测试。

### 相机端

相机端修改版与原版使用不同签名，无法直接覆盖安装原作者的安装包。首次替换时，需要先卸载相机上的原版，再安装修改版；原应用数据可能随卸载清除，请按发布说明重新配置。

后续能否覆盖安装，以对应版本的包名、签名及发布说明为准。

### 相册权限

使用本地相册功能时，如需浏览全部影集，请允许 App 访问所有照片。

不希望授予完整相册权限时，也可以使用“从文件选择”入口打开指定图片。

## 使用流程

1. 在手机上开启热点，或让手机与相机连接到可互通的 Wi-Fi 网络。
2. 打开相机端 AlphaSync，确认网络和服务已启动。
3. 打开手机端 App，按提示连接相机。
4. 进入文件页面浏览、预览或选择文件下载。
5. 需要边拍边传时，开启自动同步，并选择下载 JPG、RAW 或两者。
6. 在大图页面开启直方图、斑马纹或明暗色块，辅助查看照片。

自动同步初始化需要一定时间。请等待基线扫描完成后再测试新照片同步，不要将“已加入队列”理解为“已下载完成”。

## 兼容性与测试范围

本项目面向能够安装相机端应用的索尼相机。

当前主要测试设备：

- **相机**：Sony A7R II / ILCE-7RM2。
- **手机**：小米 13 Pro，Android 16。

其他相机型号、手机系统和网络环境的兼容性仍需验证。平板适配也在持续调整，不保证所有设备上的显示和操作完全一致。

本地构建和单元测试通过，不代表所有真实设备场景均已验证。
