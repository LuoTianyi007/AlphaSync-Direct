# AlphaSync 直连版

本项目基于 [BI2QFA/AlphaSync](https://github.com/BI2QFA/AlphaSync)
修改，是由 LuoTianyi007 维护的非官方改进版，不代表原作者的官方发布。

原作者：BI2QFA。

主要改动包括网络发现与重连优化、照片预览与自动同步优化、
平板适配，以及直方图、斑马纹、明暗色块和本地相册浏览功能。

原项目及第三方版权和许可声明予以保留，详见 LICENSE、NOTICE 和 LICENSES。

## 功能

- **配对相机**
- **更加智能的缩略图加载机制**
- **直接传输SD卡内的文件，如RAW原图**
- **相机端支持连接已有Wi-Fi或启动热点**
- **支持后台运行边拍边传**

## 兼容性

所有能安装软件的**索尼全画幅/APS-C相机**均可使用。
